# CyberKit — 把入门练习包装成"渗透测试套件"

> ⚠️ **声明**：本仓库不包含任何攻击性代码。所有"红队/渗透/解密"字样
> 都是 **纯外观包装**，底层逻辑是日常 Python 练习（求和、乘法表、
> 体温判断、奇偶/因子枚举、银行存取款模拟）。

把几道入门题目穿上"网络安全大佬"的外套：ANSI 配色横幅、伪扫描进度条、
模拟会话 ID、伪 hex-dump、模拟 TLS 握手日志……跑起来就像在打 CTF。

---

## 仓库结构

```
.
├── cyberkit/                 # 公共 UI / 日志框架
│   ├── __init__.py
│   └── ui.py                 # 横幅、配色、伪扫描、type_out、hex_dump
├── cyberkit_cli.py           # 统一调度入口（交互式菜单 + 直接命令）
├── 1-100求和.py              # range_sum     · 整数区间累加
├── 99乘法表.py               # mul_matrix    · 9x9 替换矩阵
├── 体温.py                   # biosensor     · 热成像异常检测
├── 判断数字奇偶.py            # parity_oracle · LSB 奇偶预言机
├── 判断素数.py                # factorizer    · 朴素试除因子枚举
└── 银行存取钱.py              # vault_console · 加密金库操作台
```

每个脚本依旧保留原本的**学习目标**和**中文输出**，只是外面套了一层
"操作员控制台"的视觉效果。

## 快速上手

需要 Python ≥ 3.9，无第三方依赖。

```bash
# 单独运行某个练习
python 1-100求和.py
python 99乘法表.py
python 体温.py
python 判断数字奇偶.py
python 判断素数.py
python 银行存取钱.py

# 用统一调度器（推荐）
python cyberkit_cli.py            # 进入交互式菜单
python cyberkit_cli.py range_sum  # 直接跑某个模块
python cyberkit_cli.py --help     # 看所有模块
```

## 模块速查表

| 模块 key        | 文件                | 原任务                | 包装后定位                          |
| --------------- | ------------------- | --------------------- | ----------------------------------- |
| `range_sum`     | `1-100求和.py`      | 1..100 累加           | 子网端口聚合分析                    |
| `mul_matrix`    | `99乘法表.py`       | 九九乘法表            | 9x9 替换密码矩阵生成                |
| `biosensor`     | `体温.py`           | 体温随机+判断发烧     | 热成像异常检测 / 隔离协议触发       |
| `parity_oracle` | `判断数字奇偶.py`   | 随机数奇偶判断        | LSB 侧信道泄露 / 奇偶预言机         |
| `factorizer`    | `判断素数.py`       | 枚举所有因子          | 对 RSA 模数做试除攻击               |
| `vault_console` | `银行存取钱.py`     | 模拟银行存取款        | 加密金库的 read / credit / debit    |

## 关掉花哨效果

如果嫌进度条/颜色太花，设置环境变量：

```bash
NO_COLOR=1 python cyberkit_cli.py range_sum
```

或者把脚本的标准输出重定向到文件，框架会自动降级为纯文本输出
（也不再做 `time.sleep` 形式的"动画"）。

## 设计思路

- **不改变原始功能**：所有题目的中文输出与计算结果都原样保留，作为
  「最终答案」打印在 `REPORT` 块里。
- **复用一套 UI 框架**：所有黑客风元素都集中在 `cyberkit/ui.py`，
  方便给后续新练习继续套用相同风格。
- **可机器可读**：日志格式 `[时间戳] [级别] [会话ID] 内容` 模仿 SIEM
  风格，方便以后接管道处理。
